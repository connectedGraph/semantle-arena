# 词表构建来源与口径

本目录的 `pool.json` 是**可换词表**的产物，由 `scripts/build_wordlist.py` 生成。
换词表只需改这里的源文件并重跑构建，游戏逻辑不动。

## 当前口径（2026-10-31 定）

| 项 | 取值 |
|---|---|
| 主源 | jieba `dict.txt`（MIT，349046 条，带词频与词性），词频 ≥ 200 |
| 副源 | webdict（22 万条带词频），词频 ≥ 3000，**只补 n / nz** |
| 字数 | 2 ~ 4 字，纯汉字 |
| 名词类 | `n / nz / vn / an / s / t / b / z` 直接收 |
| 动词/形容词 | `v / a` 需词频 ≥ 400 才收（高频的情绪词是好谜底） |
| 副词 | 一律不收（没有实体指称，无法猜） |
| 排除规则 | 方位后缀、虚词前缀/后缀、叠词、高频短语（`exclude.rules`）+ 人工豁免 |

产出：17751 词（二字 15090 / 三字 2338 / 四字 323）。

之后按**具象度**再切三档（`scripts/build_tiers.py`）：
精简 3000 / 标准 8000 / 完整 16033。选词方法见 [docs/engine.md](../../docs/engine.md#词库档位)。

## 五个走过弯路的口径决策

### 1. 词性白名单是错的

第一版按 `n / v / a / vn / ...` 白名单收词，结果把一大批常用词挡在外面：

| 词 | jieba 词性 | 实际是什么 |
|---|---|---|
| 西瓜 | `ns`（地名） | 水果 |
| 吉他 | `ns` | 乐器 |
| 登山 | `ns` | 运动 |
| 小提琴 | `nr`（人名） | 乐器 |
| 滑雪 | `nr` | 运动 |
| 相机 | `d`（副词） | 物品 |

jieba 的词性标注对短词不可靠。改成**只硬排除一定不是谜底的类别**
（人名 `nr*`、机构 `nt`、数词 `m`、量词 `q`、代词 `r`、虚词 `c/p/u/y/e/o`、
方位 `f`、成语 `i`、惯用语 `l`），其余全收，再靠词频和排除规则筛。

### 2. 单源不够，需要第二词源

jieba 的二字词频分布很陡：`橘子 87 / 草莓 116 / 芒果 125 / 奶茶 89`，
都低于 200 但都是日常词。webdict 的同一批词是 `橘子 9272 / 草莓 14349 / 芒果 7805`。

两个源词频量级完全不同，所以**每个源有自己的 `min_freq`**。

### 3. webdict 会把专名带进来

webdict 没有词性标注，`安德烈 / 塞尔维亚 / 中国 / 北京` 都在里面。
解法：用 jieba 的词性表做交叉校验——**若 jieba 有该词且标为专名/数词，就排除**。
这样 `中国/美国/北京` 被挡（正确），而 jieba 没收录的词照收。

### 4. 排除规则会误伤

第一版写了 `suffix:里 上 下 中 外 内 边 们 着 了 过 地 得 么`，
把 `难过 / 经过 / 通过` 全杀了（`难过` 词频 691，明显是常用词）。
改成只保留方位后缀，虚词组合改用 `exact` 逐个列。

另外叠词规则 `^(.)\1+$` 会杀掉 `星星 / 娃娃`，用 `allow:` 豁免。

### 5. 「是词」不等于「能当谜底」——这一条最容易被忽略

前四条解决的是「漏收常用词」，把池子从 1.3 万扩到 2.2 万。
但扩完做随机抽样，抽到的是这些：

```
挂职 出资 增持 批准 打开 判断 也许 激烈
当儿 平素 一村 子口 智元 黄某 库区 首款
公司 市场 记者 企业 基金 政策 方面 数据
```

前三行是动词/副词/伪词，最后一行是财经新闻高频词。
它们都能算相似度，但**玩家没法靠「联想一个具体的东西」去逼近**——
这是猜词游戏最核心的可玩性，不是精修问题。

根因是「词频」衡量的是**语料里的出现次数**，不是**可猜性**：

| 词 | webdict 词频 | 能不能当谜底 |
|---|---|---|
| 公司 | 4,183,196 | 不能（太泛，且是新闻语境） |
| 苹果 | 1,143,881 | 能 |
| 小提琴 | 3,212 | 能 |
| 挂号 | 高 | 不能（是动作不是东西） |

词频分不开「公司」和「苹果」，这两者词频在同一量级。

最终解法是**按词性分配不同门槛**，而不是单一阈值：

- `n / nz / vn / an / s / t / b / z`（名词类）→ 主源阈值 200
- `v / a`（动词/形容词）→ 词频 ≥ 400。高频的 `警察 1677 / 后悔 988 / 害怕 3404 /
  紧张 4790` 收进来（情绪词是好谜底，Semantle 原版也收），低频的
  `挂职 / 出资 / 增持` 挡掉
- `d`（副词）→ 一律不收
- webdict 源只补 `n / nz`，不补动词——它的高频区几乎全是新闻动词

代价是池子从 22479 降到 17751。**这是对的取舍**：词池的价值不在数量，
在「随机抽一个，玩家看到答案会觉得『这确实该猜出来』」。

## 换词表怎么做

`scripts/build_wordlist.py` 的 `DEFAULT_SOURCES` 是源列表，每个源独立配置：

```python
{
    "source": "jieba",
    "path": "data/sources/jieba_dict.txt",
    "format": "jieba",        # 词 词频 词性
    "min_freq": 200,
}
{
    "source": "webdict",
    "path": "data/sources/webdict.txt",
    "format": "freq",         # 词 词频
    "min_freq": 3000,
}
```

已支持 `format`：`jieba` / `freq` / `plain`（一行一词）。

```bash
# 试档位（不写文件）
python scripts/build_wordlist.py --min-freq 100 --dry-run
# 写文件并重建向量
python scripts/build_wordlist.py
python scripts/build_tiers.py
# 复核常见词覆盖
python scripts/audit_pool.py
```

`audit_pool.py` 会报告「一份常见词参照表里哪些词没进池、被谁挡住的」，
是换词表后必跑的检查。
