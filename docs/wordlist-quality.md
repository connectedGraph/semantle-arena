# 谜底质量：最难的一环

这份文档单独解释「什么词能当谜底」，因为它是这个项目里返工最多的地方。

## 问题

猜词游戏的核心体验是：**看到一个词，能联想到它是什么东西**。
`钢琴 → 乐器、音乐、小提琴`，这条路走得通。
`挂职 → ?` 走不通——它不是东西，是一个动作，而且大多数人不知道它具体指什么。

词表和谜底质量不是一回事。第一版词表（1897 词人工堆）的问题是**近义词群泛滥**；
扩充到 2.2 万词之后，问题变成了**混进大量不能当谜底的词**。

## 词频分不开「公司」和「苹果」

| 词 | webdict 词频 | 可猜性 |
|---|---|---|
| 公司 | 4,183,196 | 差（太泛，且是新闻语境词） |
| 苹果 | 1,143,881 | 好 |
| 市场 | 3,377,764 | 差 |
| 小提琴 | 3,212 | 好 |

`公司` 比 `小提琴` 词频高 1300 倍，但作为谜底，后者远好于前者。
**词频衡量的是语料出现次数，不是可猜性。**

## 判据：按词性分配门槛

`n`（名词）通常是「东西」，`v`（动词）通常是「动作」，`d`（副词）什么都不是。
所以：

| 词性 | 门槛 | 理由 | 通过 / 挡住 |
|---|---|---|---|
| `n / nz / vn / an / s / t / b / z` | 主源 200 | 名词类，天然是「东西」 | 苹果、小提琴、酸奶、天鹅 |
| `v / a` | **400** | 高频情绪词是好谜底，低频动词不是 | 过：警察 1677、后悔 988、害怕 3404、紧张 4790<br>挡：挂职、出资、增持、批准 |
| `d` | 不收 | 没有实体指称 | 也许、激烈、一直 |

第二个门槛 400 是实测出来的：`开心 487 / 焦虑 676 / 难过 691 / 后悔 988` 都在线上，
`挂职 / 出资 / 增持 / 批准` 在 200~400 之间，正好被挡。

## webdict 只补名词

webdict 的高频区几乎全是财经/新闻语料：

```
公司 市场 记者 企业 基金 政策 方面 数据 行业 产品 银行
```

它作为主源会稀释词池。所以 webdict 的定位是**补充 jieba 漏掉的具象名词**
（橘子、草莓、吉他、小提琴、奶茶），只补 `n / nz`，不补动词。

## 还剩什么噪音

17751 词里仍有少量抽象或书面词：`深表 / 声讨 / 领略 / 起色`。
它们是 jieba 标为 `n` 或高频 `v` 的词，统计口径分不出来。

这类残留靠逐词审查能清掉，但那又回到「人工审美」的老路——
本项目的取舍是**接受少量噪音，换取口径可复现、可换档位**。
`scripts/audit_pool.py` 提供的是「常见词覆盖」检查（防漏），
不是「谜底质量」检查（防滥）——后者目前没有自动判据。

## 怎么验证

```bash
# 随机抽样看手感
python -c "
import json, random
words = [w['w'] for w in json.load(open('data/wordlists/pool.json'))['words']]
random.seed(0)
print(' '.join(random.sample([w for w in words if len(w)==2], 40)))
"
```

抽 40 个二字词，如果超过 5 个你「不想猜」，就该调门槛。

## 附：这轮修掉的规则误伤

调试过程中，形态规则反复误杀真词，值得记下来：

| 规则 | 想挡 | 误杀 | 修法 |
|---|---|---|---|
| `suffix:过` | `动过 / 走过` | **难过 691 / 经过 / 通过** | 移出 suffix，改用 exact 逐个列 |
| `suffix:于` | `产于 / 忠于` | `关于 / 由于 / 终于 / 属于` | 保留 suffix，但 allow 豁免真词 |
| `suffix:着` | `背着 / 跟着` | `向着 / 沿着` | 保留（这两个本来就该挡） |
| 词频 400 硬门槛 | 低频动词 | **内疚 194 / 弹奏 126 / 懊悔 248** | allow 点名的词绕过硬门槛 |

结论：**形态规则在中文里极难写对**。「X过」既可能是动宾短语（动过），
也可能是真词（难过）。所以规则只做粗筛，方向明确的好词靠 `allow:` 人工兜底。
`allow:` 现在是全权限豁免——绕过词性、词频、排除规则三道关。
